# CCDM-CBADA bioinformatics community resources
This repository will contain resources useful to bioinformatics community members.<br>
It is intended that it will evolve as regular meetings progress and suggestions<br>
for additional resources arise. This repository does not intend to recreate
documentation for widely used software or resources, e.g. Pawsey's HPCs.<br>
Its main functions are:<br>
* To serve as a quick reference for routine computing tasks widely used in the community.
* To expand on existing documentation for the most relevant procedures with further examples and explanations.

## Let's not reinvent the wheel: useful, well-maintained tools that can be used by everyone    
### Why this section?    

Bioinformatics workflows often include common tasks such as retrieving sequencing data, collecting metadata, performing quality control, or preparing standardised input files. Instead of developing and maintaining custom scripts for tasks that are already well supported by the community, we should prioritise established, well-maintained, and reproducible tools whenever possible. This section collects useful tools that can be adopted across projects and by different members of the team, reducing duplicated effort and making our analyses easier to maintain and reproduce.     

## Fetching sequencing data from public databases
- [nf-core/fetchngs](documentation/nfcore_fetchings.md) - Reproducibly downloads sequencing data and associated metadata from public repositories using accession IDs. It includes SRA / ENA / DDBJ / GEO ids.
